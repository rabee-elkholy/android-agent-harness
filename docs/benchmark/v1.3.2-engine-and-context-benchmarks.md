# Engine, Project-Context & Multi-Wave Subagent Benchmarks (v1.3.2)

Reproducible local engine, `.agents/project-context/`, router, and multi-wave subagent governance measurements comparing the `v1.3.1` baseline against `v1.3.2`.

> **Scope note**: These measurements cover deterministic engine serialization, discovery/context payloads, warm router latency, and live 5-module Android task-lifecycle verification. End-to-end headless certification against `Automattic/pocket-casts-android` remains tracked separately in [benchmark-status.md](benchmark-status.md).

## 1. `.agents/project-context/` Efficiency & Propagation (`v1.3.1` vs `v1.3.2`)

Measured on a multi-module Android/Java fixture (`71` source/test files, `:app` + `:feature:profile`, `3` active scoped `developer-instructions.json` entries, and a bilingual `project-notes.md` containing architectural conventions plus a `15 KB` Arabic Zoho Sprints HTML ticket template):

| Surface / Operation | `v1.3.1` Baseline | `v1.3.2` Candidate | Delta | Root Optimization |
|---|---:|---:|---:|---|
| `task-context --file .../strings.xml --json` (`FILE_FALLBACK`) | `40,394 B` | `4,694 B` | **-88.38%** | Removed unused raw `project_facts` dump in `FILE_FALLBACK` and omitted pure PM/Zoho HTML sections from code discovery JSON |
| `harness.py graph --module :app --format json` | `16,689 B` | `2,130 B` | **-87.24%** | Filtered non-code PM/Zoho HTML sections in `load_code_relevant_project_notes` while adding scoped `developer_instructions` |
| Reviewer `project-notes.md` block (`phase_review.py` & `review_package.py`, non-PM tasks) | `15,408 B` | `341 B` | **-97.79%** | Stripped pure PM/Tracker HTML templates when `plan.external_writes` is empty while retaining 100% of architectural/domain notes |
| `8`-target batch `task-context --json` (`SUMMARY`) | `246,468 B` | `214,265 B` | **-13.07%** | Shared `project_notes` (`SUMMARY` deduplication) + PM HTML filtering |
| `developer-instructions.json` active surface coverage | `2 / 7` (`28.6%`) | `7 / 7` (**100%**) | **+5 surfaces** | Added to `PreInvocation`, `graph` (`--json` & `compact`), `task-context` CLI, `plan.md`, `delegate-plan`, and `phase_review.py` (`p1..pN`) |
