# ADR-008: One-Time Early GitHub Release for v1.0.61

- **Status**: Accepted for v1.0.61 only
- **Date**: 2026-09-23

## Context

The repository Constitution normally requires cross-platform CI to finish successfully before tagging or publishing a release. The maintainer explicitly requested that v1.0.61 be published on GitHub immediately without waiting for the remaining CI jobs, after being informed of that conflict and of the publication risk.

## Decision

For v1.0.61 only, the maintainer authorizes the Git tag and GitHub Release before exact-head CI completes. Local release validation, package build validation, and the completed CI jobs remain recorded as evidence. The GitHub Release must disclose that cross-platform CI is still pending at publication time.

This decision does not weaken the standing release guard for future versions. The existing PyPI workflow retains its successful CI and tag-validation requirements; publishing the GitHub Release does not authorize bypassing those controls.

## Consequences

The GitHub archive and any attached package artifact are available before all platform checks finish. If CI later fails, the maintainer must address the failure and communicate the release status without rewriting the immutable v1.0.61 tag.
